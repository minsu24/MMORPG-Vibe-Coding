# 다친 주민의 두꺼비 의뢰와 장신구

## 플레이 흐름

1. 기존 거미 10마리 퀘스트를 다친 주민에게 보고합니다. 기존 완료 대사와 직업별 대사는 유지했습니다.
2. 완료 대사가 끝나면 주민이 늪지대 두꺼비 처치 의뢰를 제안합니다. 거절해도 다시 말을 걸어 받을 수 있습니다.
3. 두꺼비를 처치하면 쓰러진 자리 근처에 두꺼비 방울 목걸이와 완료 아이콘·문구·아래쪽 화살표가 나타납니다. 접촉해도 자동으로 획득되지 않습니다.
4. 가까이에서 T키로 조사하면 독백이 나옵니다. 독백을 끝까지 마친 뒤 목걸이를 한 번 지급하고 퀘스트를 완료합니다.
5. 획득 후 “장신구들은 고유한 특수능력을 지닙니다. 게임을 진행하며 여러 장신구를 모아보세요.”라는 안내와 장착 방법이 나옵니다.

## 장신구

- 인벤토리에 장신구 탭을 추가했습니다. 기존 장비·소비·기타 분류 값은 유지했습니다.
- 목걸이·팔찌·반지를 장착할 수 있습니다. 기존 장비창 슬롯과 드래그/더블클릭 장착·해제를 사용합니다.
- 두꺼비 방울 목걸이는 제공된 투명 PNG를 그대로 사용하며 모든 직업이 장착할 수 있습니다. 고유 퀘스트 보상이므로 판매할 수 없습니다.
- 장착 중 점프 높이가 20% 증가합니다. 점프 초기 속도에는 sqrt(1.2)를 적용해 높이를 기준으로 증가시키며, 해제 즉시 기본 점프로 돌아옵니다. 아래+점프로 발판을 내려가는 속도에는 영향을 주지 않습니다.
- 효과 값은 `Assets/_Project/Data/Items/ToadBellNecklace.asset`의 Special Ability Value에서 조절합니다. 0.2는 높이 20%입니다.
- 필수 진행 구간이나 목걸이가 있어야만 통과할 수 있는 지형은 추가하지 않았습니다.

## 진행 보호

- 먼저 두꺼비를 잡은 뒤 의뢰를 받아도 완료할 수 있습니다.
- 미획득 상태에서 지역을 나갔다 돌아오면 조사 대상이 복원됩니다.
- 장신구 인벤토리가 가득 차면 보상을 잃지 않고 빈 칸을 만든 뒤 다시 조사할 수 있습니다.
- 중복 처치 이벤트·대사 완료 이벤트로 보상이 중복 지급되지 않습니다.
- 독백이 중간에 끊기면 보상을 지급하지 않습니다.
- 자동 저장은 이번 작업에 포함하지 않았습니다. 진행 상태는 기존과 같이 플레이 세션 안에서 유지됩니다.

## 검증과 재설정

- `Eastern Fantasy > Quest > Validate Toad Hunt and Accessories`: 세 직업 장착, 드래그 슬롯 구분, 실제 물리 점프 높이, 보상과 예외 흐름을 검증합니다.
- `Eastern Fantasy > Quest > Run Toad Hunt Play Validation`: 플레이 모드에서 실제 씬·주민 대사·수락 선택·보스 사망·T키 상호작용·독백 완료·장비창 드롭을 자동 검증합니다. 검증은 현재 플레이 진행을 변경하므로 별도 테스트 실행에서 사용하세요.
- `Eastern Fantasy > Quest > Setup Toad Hunt and Accessories`: 데이터·프리팹 연결을 재생성합니다. 일반적인 플레이에는 실행할 필요가 없습니다.
- `Validation.txt`, `PlayValidation.txt`에 결과를 기록하고 `AccessoryEquipment.png`, `QuestRelic.png`에 미리보기를 기록합니다.
