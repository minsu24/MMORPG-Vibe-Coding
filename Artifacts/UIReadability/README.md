# UI 가독성 개선

12개 게임 씬과 공용 UI 프리팹을 점검하고, 14개 UI 프리팹 및 3개 씬의 텍스트 배치를 수정했습니다. 프리팹을 사용하는 나머지 씬에도 변경이 반영됩니다.

- 본문은 주로 20~30px, 수량 등 작은 표시는 최소 18px로 조정했습니다.
- 상점 이름·직업 제한·가격, 승급 재료 수량·비용·안내 문구의 공간을 확보했습니다.
- 스탯 문구의 불필요한 줄바꿈을 제거하고 테두리 안으로 배치했습니다. 한글을 표시하지 못하던 직업·닫기 안내 글꼴을 교체했습니다.
- 밝은 종이 배경의 대사와 스킬 제목은 진한 글씨로 바꿨습니다.
- 아이템·스킬 툴팁, 퀘스트 목록, 긴 대사는 마우스 휠 또는 드래그로 읽을 수 있습니다. 본문을 마스크 영역 안에 제한하고 툴팁이 화면 밖으로 넘어가지 않도록 보정했습니다.
- 툴팁으로 포인터를 옮겼을 때 바로 닫히지 않도록 지연 처리를 추가했습니다.

## 확인

- Unity 스크립트 컴파일 오류 없음.
- 1920×1080 에디터 프리뷰 렌더링으로 주요 창, 메인 메뉴, 직업 선택, 스탯·대사창을 확인했습니다. PNG 파일은 이 폴더에 있습니다.
- 긴 툴팁 본문의 마스크, 최소 글자 크기 및 스크롤 끝 이동 확인.
- 기존 EquipmentUpgradeValidation, EquipmentSetValidation 통과: 부족한 재료/엽전 처리, 버튼 이벤트, 승급 거래, 6종 세트 효과, 아이템/프레임 정렬.
- 플레이 모드의 전체 게임 진행 및 모든 해상도 조합을 자동 검증한 것은 아닙니다.
