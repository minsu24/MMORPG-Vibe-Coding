# 방어구 이미지 교체

preview.png: 행은 위부터 일반, 희귀, 영웅, 설화, 신화. 열은 모자, 상의, 하의, 장갑, 신발.

원본: Assets/_Project/Art/Item/ArmorSets/Sources/
아이콘 25개: Assets/_Project/Art/Item/ArmorSets/Icons/

각 아이콘은 투명 배경의 512x512 정사각형입니다.
그림을 찌그러뜨리지 않고 원래 비율을 유지해 긴 변 448px로 통일했습니다.
모든 그림은 실제 보이는 픽셀의 경계를 기준으로 중앙에 배치했습니다.
양손 장갑과 양발 신발은 각각 한 아이템으로 묶었습니다.
시트의 아이템 사이를 다각형 경계로 분리하고, 이웃 아이템에서 떨어져 나온 픽셀 조각을 제거했습니다.
설화·신화의 연결된 광채는 유지하되 겹치는 경계의 잔광은 정리했습니다.

기존 ItemDefinition 25개와 등급별 Appearance의 아이콘 참조를 교체했습니다.
공통 UI 경로를 통해 상점, 인벤토리, 장비 창, 툴팁과 승급 창에 적용됩니다.
아이템 ID, 수치, 세트, 직업 제한, 승급 조건, 기존 등급 프레임은 유지했습니다.

Eastern Fantasy > Inventory > Replace Training Armor Images 메뉴에서 다시 생성할 수 있습니다.
Center All Item Icons 메뉴도 이 아이콘의 정사각형 여백을 유지합니다.
Setup Item Grades 메뉴를 다시 실행해도 새 방어구 이미지가 적용됩니다.

중앙 정렬, 512px 정사각형과 균일한 크기를 확인했고, 기존 장착·승급·세트 효과 검증도 통과했습니다.
