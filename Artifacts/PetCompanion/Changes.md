# 동행요괴 프리팹과 AI

## 프리팹

`Assets/_Project/Prefabs/Companions/GoblinCompanion.prefab`

- 기존 Goblin의 대기 6프레임과 이동 8프레임을 사용.
- 공격은 도깨비 공격 2-1468 / 2-257의 유효한 7프레임을 1, 2, 4, 5, 6, 7, 8 순서로 재생. 3번은 원본의 투명 프레임이라 제외.
- 공격 길이 0.8초, 타격 시점 0.6초. 대기·이동은 반복, 공격은 1회 재생.
- 루트 배율은 기존 몬스터의 1/1.5, 약 ⅔. 투명 여백을 제외한 기본 자세 크기로 대기·이동·공격을 맞춤. 각 모션의 배율을 고정해 무기를 들거나 웅크리는 동안 몸이 확대·축소되지 않음.
- Entity, 체력, 피격 콜라이더, Rigidbody, 몬스터 AI는 없음.

## AI

플레이어의 기본 공격·투사체·기술이 맞힌 적을 전달받아 함께 공격한다. 가까운 적을 스스로 선택하지 않는다.

`대기 → 접근(속도 10) → 공격 → 복귀(속도 12) → 플레이어 옆 대기 → 반복`

- 공격 시작 사이의 최소 주기 4초. 실제 이동까지 포함한 검증 간격은 약 4.35초.
- 한 공격의 타격 프레임에서 한 번만 피해를 준다.
- 플레이어의 새 공격 대상을 다음 공격에서 선택한다. 진행 중인 공격은 해당 타격 대상에 고정된다.
- 대상 사망·소실 시 복귀하여 대기. 일시정지 및 플레이어 사망 시 공격 중지.
- 소환과 성장 비용은 이전 동작 유지: 최초 영혼 1개, 성장에 현재 레벨만큼 SoulFragment 사용.

## 목록과 향후 등록

`Assets/_Project/Resources/PetCompanionCatalog.asset`의 `Companion Prefabs` 배열에 동행요괴 프리팹을 넣으면 UI가 행을 생성한다. 프리팹에는 PetCompanionActor가 있어야 하며 Companion ID를 각각 다르게 지정한다.

현재 등록은 도깨비 1개. 저장된 UI와 실행 목록에는 도깨비와 확인용 `???`만 표시한다. `???`는 소환할 수 없으며 카탈로그의 Show Placeholder로 숨길 수 있다.

- 전체 런타임·에디터 코드 컴파일: 오류 0개, 기존 코드 경고만 발생.
- 별도 Unity 6000.3.23f1 프로젝트에서 실제 프리팹·스프라이트를 가져오고 모든 애니메이션 키를 샘플링하여 기본 자세 크기와 모션 내 고정 배율 확인.
- 실제 PetCompanionActor를 플레이어·적 어댑터와 함께 격리 Play Mode에서 실행: 임의 적 선택 방지, 대상 추적, 4초 주기, 복귀·대기, 재타겟, 대상 사망, 일시정지, 플레이어 사망 통과.
- 실제 게임의 공격 경로는 컴파일 및 호출 위치 확인. 원래 게임 씬에서의 통합 플레이 검증은 수행하지 않음.
- 최종 프리팹 내부 참조·카탈로그 등록·UI 2행 구조 검사 통과.
- `GoblinCompanionPreview.png`: 왼쪽부터 기존 크기, 펫 대기, 펫 이동, 펫 공격 타격 자세.
- 재생성 메뉴: Eastern Fantasy/Companions/Setup Goblin Companion Prefab.

## 장착 / 장착 해제 추가

- 소유·성장 상태와 장착 상태를 분리. 최초 영혼 소환은 기존처럼 자동 장착한다.
- 하단에 장착 / 장착 해제 전환 버튼 추가. 재장착·해제는 영혼과 SoulFragment를 소비하지 않는다.
- 해제하면 월드 동행 오브젝트를 즉시 비활성화하고 제거한다. 레벨·공격력·소유 상태는 유지.
- 해제 상태에서 성장하거나 목록을 선택해도 자동 재등장하지 않는다. 목록 미리보기 선택과 실제 장착을 분리.
- 씬 전환 후 장착된 동행만 복원. 캐릭터별 동시에 한 마리만 장착.
- 성장·소환·장착 상태 검사 24개 통과. 전체 코드 컴파일 오류 0개.
- 격리 Unity Play Mode에서 해제 후 오브젝트 0개, 해제 중 성장, 재장착 후 성장 상태를 유지한 오브젝트 1개 확인.
- 프리팹 내부 참조, 버튼 연결과 겹침 없음 검사 통과. 실제 원본 게임 씬의 버튼 클릭 통합 검증은 수행하지 않음.

## 거리 제한 제거와 전투 상태 연결

- 같은 씬의 살아 있는 공격 대상은 거리 제한 없이 접근·공격·복귀한다. 이전 14유닛 추적 제한과 거리 초과 시 강제 복귀를 제거.
- PlayerEntity.IsInCombat / RegisterCombat / EndCombat 추가. 플레이어가 타격하거나 피해를 받으면 전투를 갱신하고, 기본 10초 동안 갱신이 없으면 전투 해제. 무사는 기존 MonkEnergy의 Combat Timeout 설정을 공유.
- 동행요괴의 공격으로 플레이어의 전투 시간이 갱신되지 않으므로 혼자 계속 공격하며 전투를 유지하지 않는다.
- 전투 해제 시 접근·공격 준비를 취소하고 복귀하여 대기. 재전투는 플레이어의 새로운 공격 대상 전달로 시작.
- 접근 측면과 공격 방향을 한 공격 동안 고정. 이동 시 방향을 중복으로 덮어쓰던 처리 제거.
- 플레이어 추적 시작 거리는 0.5, 도착 판정은 0.1로 분리해 작은 위치 변화에 대기/이동 모션이 반복 전환되지 않도록 함.
- 이동 속도를 접근 10 / 복귀 12로 조정. 공격 중 움직이는 대상은 고정된 공격 방향을 유지하며 따라간다.
- 상태·전투 만료·공격 취소 검사 33개 통과. 전체 코드 컴파일 오류 0개.
- 격리 Unity 실행: 65유닛 대상 타격·복귀, 접근/공격 준비 중 전투 종료, 작은 위치 떨림에도 대기 유지, 적이 도깨비를 가로질러도 공격 자세 방향 유지 확인.

## 공격하지 않는 문제 수정 (2026-10-15)

원인 1: 모든 플레이어 프리팹의 PlayerLocationSetter가 플레이어를 DontDestroyOnLoad 씬으로 옮긴다. PetCompanionActor는 적과 플레이어의 씬이 같아야 대상을 선택했고, UI도 동행을 플레이어의 유지 씬으로 이동시키고 있었다. 실제 맵의 적을 거부하는 구조였다. 플레이어를 유지시키는 동일한 조건에서 전투 상태와 LastAttackTarget은 정상인데 도깨비 대상이 null이며 타격 0회인 것을 재현했다.

수정: 동행을 활성 게임 맵에 생성하고, 대상 검증은 동행의 게임 맵을 기준으로 수행한다. 유지 씬에 남은 이전 동행도 게임 맵에서 재생성한다.

원인 2: 이동 전에 도착 판정을 했다. 플레이어가 매 프레임 0.1유닛보다 더 움직이면 복귀 판정에 도달하지 못해 공격 상태로 전환하지 못했다. 플레이어 속도 6.6, 60FPS 조건에서 대상은 지정됐으나 계속 Returning 상태와 타격 0회인 것을 재현했다.

수정: 이번 프레임 이동을 먼저 반영하고 도착·타격을 검사한다. 프레임당 이동을 중복 적용하지 않으며, 움직이는 적에 대한 공격 준비 이동도 타격 판정보다 먼저 처리한다.

검증: 실제 PetCompanionActor와 플레이어/적 어댑터를 사용하는 별도 Unity Play Mode에서 DontDestroyOnLoad 플레이어, 달리는 플레이어, 속도 8의 이동 적 타격, 전투 해제 후 추가 공격 없음 통과. 원래 게임 씬의 전체 플레이 검증은 수행하지 않았으며, 실제 프리팹의 유지 컴포넌트 및 모든 공격 대상 전달 경로는 소스와 컴파일로 확인했다. 재현 결과는 AttackRegression.txt에 기록.


## 도깨비 액티브 기술

- GoblinGiantStrike 스킬 정의와 프리팹 참조 추가. 소환 시 스킬 포인트 없이 해금되며 동행요괴 창의 혼령 기술 아이콘을 기존 퀵슬롯에 드래그하여 등록한다. 아이콘은 도깨비 스킬 아이콘_1이다.
- 드래그 동안 숨겨진 퀵슬롯 Canvas를 표시하고 창을 흐리게 한다. 종료 시 표시·정렬·레이캐스트 상태를 복원한다. 기존 장식용 기술 칸의 레이캐스트도 활성화했다.
- 플레이어 단축키로만 시전한다. 장착한 도깨비와 현재 살아 있는 전투 대상이 필요하다. 별도 직업 자원 소모 없이 15초 쿨타임이며 장착 해제로 초기화되지 않는다.
- 접근 → 거대화 6프레임 → 스킬 공격 6프레임 → 거대화 역순 6프레임 → 플레이어 복귀. 135/246의 좌우 순서를 각각 읽어 1,2,3,4,5,6으로 교차 연결했다. 타격 프레임에서 시전 시 도깨비 공격력의 500%를 한 번 적용한다. 거대화 때 작은 좌우 몸 떨림을 추가했다.
- 프레임 여백과 피벗 차이를 보정하고 발을 기준으로 크기를 맞췄다. 공격 후 대상이 죽어도 이미 시작한 타격 모션은 마무리한다. 타격 전 전투 종료나 대상 사망 시 피해 없이 축소한다. 평타 중복 피해를 막고 평타 쿨타임도 계속 진행한다.
- 전체 런타임/에디터 코드 컴파일 오류 0. 격리 Unity Play Mode에서 실제 스킬·퀵슬롯·드래그 컴포넌트로 등록/재배치, 500% 타격과 타격 프레임, 일시정지, 취소, 장착 변경 후 쿨타임, 직업 스킬 라우팅 확인. UI 창과 직업 플레이어/적 의존성은 테스트 어댑터를 사용했다. 원래 게임 씬 전체의 화면 조작은 아직 검증하지 않았다. 프레임 렌더는 GoblinSkillFrames.png, 실행 결과는 SkillRegression.txt에 기록했다.


## 동행요괴 첫 열기 안내

- 캐릭터별 세션 첫 창 열기에 6단계 설명 대화와 목록/소환/장착/성장/혼령 기술 강조를 추가했다. 다음 버튼 또는 Space로 진행하고 안내 닫기로 완료할 수 있다. 창을 중간에 닫으면 다음 열기에 안내를 재시작하며, 완료한 캐릭터에는 같은 플레이에서 다시 표시하지 않는다.
- 소환 이후 같은 버튼이 성장으로 변경됨을 설명한다. 전용 영혼과 공통 성장용 영혼 조각, 첫 소환 자동 장착, 장착 해제 시 성장 보존, 기술의 퀵슬롯 드래그 등록을 안내한다.
- 안내는 실제 소환/성장 버튼을 누르거나 재료를 소모하지 않는다. 밝게 강조한 부분도 안내 중 입력을 차단해 실수로 재료를 쓰지 않도록 했다. 게임 일시정지를 유지하고 강조 애니메이션은 unscaledTime을 사용한다.
- 전용 영혼 보유 시 목록에서 잠금 해제 상태로 전환된다. 영혼 보유 확인은 재료를 소모하지 않으며 기존 소환 기록도 해금으로 취급한다. 공통 영혼 조각은 요괴 잠금 해제에 사용되지 않는다.
- 전체 코드 컴파일 통과. 별도 Unity Play Mode에서 실제 UI 프리팹 위에 안내를 렌더링해 6단계, 텍스트/버튼 크기, 강조 부분 입력 차단, 일시정지 중 진행, 완료/중단/재시작, 재료 보존과 기존 성장 동작을 확인했다. 원래 게임 씬의 첫 열기 연동은 소스와 컴파일로 검증했다. 결과: TutorialValidation.txt 및 TutorialStep0~5.png.
