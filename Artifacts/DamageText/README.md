# 데미지 숫자 표시 수정

- 공통 프리팹: Assets/_Project/Prefabs/Text (TMP).prefab
- 원인: 숫자 sortingOrder가 0이어서 Default 레이어의 1~7 이상 배경/몬스터 뒤에 가려졌습니다. 1000으로 올렸습니다.
- 기존 프리팹은 Dokdo-Regular 폰트에 DNFBitBitv2의 재질을 연결하고 있었습니다. 현재 폰트의 재질로 맞췄습니다.
- EnemyController.DamageTextPosition으로 기존 앵커를 유지하되 콜라이더 상단 + 0.25보다 낮지 않도록 합니다. 달구지의 루트 앵커 등 몸통 높이의 표시를 보정합니다.
- 승려 연타/검객 연속 베기도 같은 위치 계산을 사용합니다. 기존 다중 타격의 중복 표시 억제는 유지합니다.
- 점검: 인삼, 귀신, 거미, 달구지, 멧돼지, 거인, 개구리/두꺼비, 도깨비 총 8종의 일반/치명타/중복 억제 검증 통과.
- Ginseng-before.png / Ginseng-after.png: 같은 숫자의 그리기 순서만 0/1000으로 바꿔 실제 안개 산맥에서 렌더링한 비교.
- Validation.txt: 별도 테스트 저장 폴더에서 실행한 실제 피격 검증. 사용자 저장 및 편집 씬은 보존합니다.
